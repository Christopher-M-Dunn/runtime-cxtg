# docs/flowchart_adr_life_cycle.drawio.svg

ADR lifecycle state machine diagram, editable in draw.io/diagrams.net (the mxGraph source is embedded in the SVG — open the file directly in draw.io to edit).

## Description

Shows the state transitions and cross-links for `docs/ADR_log.md` entries across its three categories — Decisions (`deferred` → `pending` → `in progress` → `incorporated`, plus `superseded`), Bugs (`open`/`closed`), and Notes (`active`/`retired`) — along with the branch points that decide where a new or reworked entry lands.
