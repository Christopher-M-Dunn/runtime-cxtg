# docs/CHARTER.md

Offline copy of the RISC-V Composable Custom Extensions Task Group charter, the document that defines what the TG is chartered to produce. The live copy lives on the RISC-V wiki; this copy carries a note naming its draft date.

## Scope

- Defines the TG's objectives, acceptance criteria, exclusions, and collaborating groups
- The **Exclusions** section is the operative one for this project: the TG is scoped to the *minimum* set of standards enabling practical composition, not a broader mandate
- Used as a guardrail — proposed work, blocks, or doc scope that falls outside the charter's objectives is mission creep

## Contents

- Introduction — the fragmentation problem CX interop standards address
- Objectives — composability criteria, ISA extensions, non-ISA CX API/ABI, optional CXU logic interface
- Acceptance criteria — Proof-of-Concept with reference designs, end-to-end software PoC, Sail support and ACT tests
- Exclusions and Collaborations — minimum-standards scoping; governing committee is Privileged IC
