# docs/flowchart_QEMU_automation.svg

QEMU build automation map: which files are entry points a developer writes, which outputs the build system generates from them, and which are fully manual.

**Note:** this flowchart is generated, and has not been rigorously verified against the QEMU build system. Treat it as orientation, not as authority — confirm against the source and the build output before relying on any detail.

## Purpose

Consulted before adding any instruction, helper, trace event, extension flag, or source file. QEMU has several interacting automation layers, and editing a generated output instead of its entry point produces silent failures or is overwritten on the next build. The diagram identifies the topmost layer appropriate to each kind of change.

## Description

SVG flowchart, colour-keyed by degree of automation — auto-generated by the build system, partially automated (declare an entry, the system generates wrappers), or fully manual.

Layers covered:

- **Meson** — `target/riscv/meson.build` sourceset registration
- **Decodetree** — `scripts/decodetree.py` over `insn32.decode`/`insn16.decode`, generating arg structs, bit-extract functions, and the `decode_insn32()` dispatch tree that calls `trans_NAME()`
- **`DEF_HELPER_N`** — the X-macro three-pass include that yields the `helper_*` prototype and the `gen_helper_*` TCG wrapper
- **ISA extension registration** — the pipeline from `BOOL_FIELD` in `cpu_cfg_fields.h.inc` through `MULTI_EXT_CFG_BOOL` and `ISA_EXT_DATA_ENTRY` in `cpu.c` to a user-visible `-cpu` flag, plus optional KVM sync
- **Trace events** — `trace-events` lines generating callable `trace_*()` functions
- **`translate.c`** — the convergence point; `trans_*.c.inc` files are `#include`d into this single translation unit rather than compiled separately
- **`disas/riscv.c`** — fully manual, not connected to decodetree; requires three separate hand edits per instruction

It closes with a summary table of common change types, the files each requires, and what the build system generates in return.
