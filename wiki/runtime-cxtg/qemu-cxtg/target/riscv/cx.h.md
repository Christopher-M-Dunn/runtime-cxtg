# qemu-cxtg/target/riscv/cx.h

CX extension interface header. Declares the CSR handler prototypes implemented in `cx.c` for use by `csr.c` (CSR table registration). Header guard: `RISCV_CX_H`. TCG helper prototypes (`helper_cxsetsel`) are not declared here — they are generated by the `DEF_HELPER_*` macro system in `helper.h`.

**Works with:**
- [cx.c](cx.c.md) — provides all function bodies declared here
- [csr.c](csr.c.md) — registers `cxsel_csr_read`, `cxsel_csr_write`, `cxsidx_csr_read`, `cxsidx_csr_write`, and `cxsdata_csr_op` in the `csr_ops[]` table
- [helper.h](helper.h.md) — declares `DEF_HELPER_2(cxsetsel, tl, env, tl)`; the macro system generates the C prototype, not this file

---

### `cxsel_csr_read` / `cxsel_csr_write`

```c
void cxsel_csr_read(CPURISCVState *env, uint32_t reg_index, target_ulong *val);
void cxsel_csr_write(CPURISCVState *env, uint32_t reg_index, target_ulong val);
```

CSR table read/write handlers for `cxsel`. The write handler is a no-op stub — `cxsel` is URO (user read-only); direct CSR writes trap via address encoding rather than through this handler.

---

### `cxsidx_csr_read` / `cxsidx_csr_write`

```c
void cxsidx_csr_read(CPURISCVState *env, uint32_t reg_index, target_ulong *val);
void cxsidx_csr_write(CPURISCVState *env, uint32_t reg_index, target_ulong val);
```

CSR table read/write handlers for `cxsidx`. Reads and writes `env->cxsidx` directly.

---

### `cxsdata_csr_op`

```c
RISCVException cxsdata_csr_op(CPURISCVState *env, int csrno,
                              target_ulong *ret_value,
                              target_ulong new_value, target_ulong write_mask);
```

Combined `.op` handler for all `cxsdata` CSR variants (csrr, csrw, csrrw, csrrs, csrrc). Using `.op` instead of separate `.read`/`.write` ensures `cxsidx` increments exactly once per instruction regardless of variant.
