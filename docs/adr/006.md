# ADR-006: Comment the `cxsel`-vs-`~0` readback shortcut wherever used

**Block(s):** all
**Parent(s):** [ADR-005](005.md), [ADR-007](007.md)

Whenever code checks `cxsel`'s readback against `~0` (e.g. `bne`) to detect an invalid selector, mark it with `// not portable, project-specific WARL choice`: the spec guarantees `~0` is always invalid, but not that `~0` is *the* legal invalid value `cxsel` holds — that's this project's own choice (ADR-005), not a portable spec guarantee. Wholly dependent on ADR-007: if that WARL-simplification proposal is adopted, `~0` becomes legal and required everywhere, and this comment (and the caveat behind it) goes away.
