# ADR-014: Wiki lint procedure

**Block(s):** all

Make a procedure to check the wiki for consistency against its source files and `wiki/schema.md`'s rules — this was planned but never actually built; nothing under this name exists anywhere in the repo yet.

**Open question:** should this future lint procedure also validate `ADR_log.md`/`docs/adr/`'s own internal consistency (ID sequence has no gaps or duplicates, every log row has a matching `docs/adr/NNN.md` file and vice versa, a row's Status and Title matches its file's own Transitions table, Parent/Children citations are reciprocal) — not just the rest of the wiki?
