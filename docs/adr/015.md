# ADR-015: Phase/block-level gate-check flow is undocumented beyond one sentence

**Block(s):** all

`flowchart_adr_life_cycle.drawio.svg` diagrams entry *statuses and transitions* only. How starting a new block actually checks `ADR_log.md` for open `deferred`/`pending`/`?`-block(s) entries affecting it — the "gate check" `docs/README_docs.md` already references — is currently one prose sentence in the root `CLAUDE.md`'s "Starting a New Block" step 2, and `qemu-cxtg/CLAUDE.md`'s per-block workflow has no gate-check step at all.

A dedicated procedure (ideally its own flowchart, matching the project's existing `flowchart_*` diagrams) is still needed. It is possible that the ideal solution keeps both: the flowchart for humans, and an efficient prose directive for Claude.

**Update:** the prose-directive half is now written — `CLAUDE.md`'s "Starting a New Block" step 2 and its "Mid-Block ADR Changes" section. The flowchart-for-humans half is still outstanding.
