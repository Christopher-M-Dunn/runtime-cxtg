# ADR-003: Mark provisional CSR/encoding values wherever used in code

**Block(s):** all
**Parent(s):** [ADR-002](002.md)

Whenever one of these raw values (not the named constant) is used directly, mark it with `/* provisional, pending RISC-V org assignment — see ADR-002 */`:

| Symbol | Value |
|--------|-------|
| `CSR_CXSEL` | `0xCA0` |
| `CSR_CXSIDX` | `0x018` |
| `CSR_CXSDATA` | `0x019` |
| `MATCH_CXSETSEL` | `0x00004073` |
| `cxdiscard` opcode | TBD |
