# Wiki Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring all wiki pages into conformance with the updated schema: YAML front matter, combined nav line (← Main Index | ↑ parent | ↗ view source), Format C back-to-top links, wc-l-based A/C threshold (> 125), non-code → D, and a conformance log pass feeding final schema and CLAUDE.md cleanup.

**Architecture:** Eight sequential passes — schema first, then structural bulk edits, then format-by-format content passes, then cleanup. Each pass operates on a well-defined set of files, with a commit after each task.

**Tech Stack:** Markdown, GNU sed, git

## Global Constraints

- All wiki pages live under `wiki/runtime-cxtg/`. `wiki/index.md` and `wiki/schema.md` are top-level siblings.
- Front matter goes only on main pages — not sub-pages.
- Every page except `wiki/index.md` and `wiki/schema.md` gets a navigation line as the first line. The line combines italic links separated by `|`: `*← [Main Index](path)*` always; `*↑ [parent-basename](../parent.md)*` on sub-pages only; `*↗ [view source](path)*` always. Source path is relative from the wiki file's location to the source file in the repo. `wiki/schema.md` gets only `*← [Main Index](index.md)*` (it is a meta-file, not a source wiki page).
- Log file: `wiki/wiki_fix_log.md` — created in Tasks 4–7, deleted in Task 8.
- One commit per task. Stage only the files listed in that task.
- Spec: `docs/superpowers/specs/2026-06-25-wiki-fix-design.md`
