```markdown

|---|---|

**Checking cloc:** `cloc <source-file>` — use the "code" column (excludes comments and blank lines). For `.inc` files not auto-detected: `cloc --force-lang=C <file>`.

**Checking Format B eligibility (submodules only):** All files in `runtime-cxtg/` are de-novo; none are Format B. For submodule files (e.g., `qemu-cxtg/`), check against the upstream release tag — NOT the project's own `cxtg` branch, which will accumulate project files over time:
```bash
git -C qemu-cxtg show v10.2.90:<path-relative-to-submodule-root> 2>/dev/null \
  && echo "upstream" || echo "new"
```
Verify the tag with `git -C qemu-cxtg tag` if uncertain.

**Format A/C reassessment:** When updating a Format A page, re-run `cloc` on the source. If it has grown to ≥ 100 lines, convert to Format C. Conversion in the other direction follows the same check.

## Task 4: Format A pass

**Files:** 11 Format A main pages. `Makefile.md` requires a full content rewrite (Format C → A conversion). The other 10 need source link insertion and conformance checks.

**Conformance checklist for Format A pages:**
- Front matter present (`format: A`) ✓ (done in Task 3)
- "up" link present as first visible element ✓ (done in Task 2)
- Title is a plain `# heading` (not a link)
- Source link on the line immediately after the title
- One-to-two sentence description after source link
- `**Works with:**` block if applicable
- `---` dividers between sections
- `### Section heading` for each symbol/block
- Code block with the actual code, verbatim
- Explanation below code (WHY, not WHAT; omit if self-evident)
- No phase/block annotations
- No line number references
- No history prose ("previously called X", "was changed from Y to Z")
- No stale symbol names (`ext_zicx`, `cxidx`, `cxdata`)

**Log format:** `wiki/wiki_fix_log.md` — one entry per issue:
```
